# Homebrew tap for Dove

[Dove](https://github.com/dominik-lenhart/dove) is a self-hosted MCP server that gives AI agents token-scoped read and
draft access to your mailboxes.

```sh
brew install dominik-lenhart/tap/dove
```

or

```sh
brew tap dominik-lenhart/tap
brew install dove
```

The formula installs the `dove` binary from the signed GitHub release (macOS arm64 and Intel, Linux x86_64 and
arm64). It does not register a background service: set Dove up with the
[deployment guide](https://github.com/dominik-lenhart/dove/blob/main/docs/deployment.md), or run it on your own
computer once local mode is documented in the main repository.

`Formula/dove.rb` is generated by the release workflow of the Dove repository (`deploy/homebrew/render.sh`, from the
release's `SHA256SUMS`) and pushed here with a deploy key. Do not edit it by hand; open issues and pull requests in
the [main repository](https://github.com/dominik-lenhart/dove).
